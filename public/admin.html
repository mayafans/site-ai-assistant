AI 助手平台 · 站点配置

请先登录；首次启动的管理员账号打印在服务端日志里（也可用 ADMIN_USER / ADMIN_PASSWORD 环境变量指定）。

业务站点

每个站点独立配置 LLM、技能、业务请求和话术。

基础

LLM

对话与外观

技能（SKILL.md）

技能 = 名称 + 触发描述 + 说明正文；模型需要时会用 skill 工具加载正文。

业务请求（服务端 HTTP 工具）

示例：查订单 → GET https://api.example.com/orders/{orderId}；参数用 JSON Schema 描述。

用户与权限

改密码或删用户会让对方已登录的会话立即失效；至少保留一个管理员。

接入代码

把脚本放到业务页面 <head> 或 <body> 末尾即可；同源时可省略 data-api-base。
